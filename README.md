# La Hilda — Frontend

Vidriera, panel admin y panel chofer, conectados a la API real en Railway (`hilda-production.up.railway.app`).

## Uso local
```bash
npm install
npm run dev
```

## Deploy en Vercel
1. Subí este repo a GitHub (con GitHub Desktop, igual que el backend).
2. En vercel.com, "Add New Project" → importá el repo.
3. Vercel detecta Vite solo. No hace falta tocar nada. Deploy.
4. Te da una URL pública tipo `la-hilda-frontend.vercel.app`.
